# レシピ管理システムでできること

## 基本機能

- **レシピを登録・編集・削除できる**
  - タイトル、説明文、何人前かを入力
  - レシピに使う食材と分量を設定
  - レシピにタグ（和食、簡単、時短など）をつけて分類

- **タグを管理できる**
  - 自由にタグを作成・編集・削除

- **食材を管理できる**
  - 自由に食材を作成・編集・削除

## 便利機能

- **レシピをキーワードで検索できる**
  - タイトルや説明文から探せる

- **タグでレシピを絞り込める**
  - 「簡単」なレシピだけ表示、など

- **買い物リストを自動生成できる**
  - 作りたいレシピを複数選ぶと、必要な食材と分量をまとめてリスト化してくれる
  - 例：カレーと味噌汁を選ぶ → 玉ねぎ（2個、1/2個）のように合算表示

- **統計情報を見られる**
  - 登録レシピ数、タグ数、食材数
  - よく使われているタグのランキング
