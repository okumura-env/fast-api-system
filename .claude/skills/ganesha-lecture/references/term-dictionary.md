# 用語→やさしい言葉 変換辞書

## 変換の原則

1. **機能で命名する**: 「何をするものか」で名前をつける
2. **身近な比喩を添える**: 日常生活での類似物を示す
3. **初出時に解説**: 専門用語が最初に出てきたとき必ず、やさしい言葉とたとえで説明する

---

## よく使う変換表

### プログラミング基礎

| 専門用語 | やさしい言葉 | たとえ |
|---------|------------|--------|
| コールバック関数 | チェック係 | 「何かあったら呼んでね」と登録しておく処理 |
| API | 窓口 | 銀行の窓口。決まった書類を出すとサービスを受けられる |
| 変数 | 名前付きの箱 | ラベルを貼った引き出し |
| 関数 | 処理の塊 | 自動販売機（入れると出てくる） |
| データベース | 情報の倉庫 | 図書館の書庫 |

### セキュリティ

| 専門用語 | やさしい言葉 | たとえ |
|---------|------------|--------|
| 認証 | 本人確認 | パスポートを見せる |
| 認可 | 許可 | 「この部屋に入っていいですよ」 |
| トークン | 入場券 | 映画のチケット |
| 暗号化 | 鍵をかける | 暗号で手紙を書く |

### AI

| 専門用語 | やさしい言葉 | たとえ |
|---------|------------|--------|
| プロンプト | 指示文 | AIへの依頼書 |
| コンテキスト | 文脈 | 会話の流れ |
| エージェント | 自動で動くAI | 自分で判断する秘書 |

## MD内での用語解説の書き方

専門用語の初出時に、以下のパターンで解説する:

```markdown
> 💡 **「コールバック関数」とは？**
> 難しそうな名前ですが、要は**「呼び出されたときに実行される処理」**のこと。
> 電話の「コールバック（折り返し電話）」と同じで、「何かあったら呼んでね」と登録しておく処理です。
> この解説では「チェック係」と呼びます。
```
