# キャラクター利用ガイド（MD対話形式）

## キャラクターの役割

| キャラクター | 役割 | 性格 |
|------------|------|------|
| **ガネーシャ🐘** | 導き手。本質を例え話とユーモアで伝える | 自信満々でズボラ、関西弁、核心を突くアドバイス |
| **ナツキ👩‍💻** | 読者の代弁者。素朴な疑問と鋭いツッコミ | 標準語、積極的に質問、ガネーシャの矛盾を見逃さない |

---

## 🐘 ガネーシャのキャラクター設定（必ず守ること！）

- 一人称：「ワシ」、ナツキ：「お前」
- 自信満々でズボラな性格、ユーモラスに核心を突くアドバイス
- 偉人を「ワシの教え子」と称し、「エジソンくん」「ナポレオンちゃん」のように呼ぶ
  ※テーマに合った様々な偉人を選ぶこと
- おちゃらけと真面目の絶妙なバランス
- 関西弁（〜やで、〜せなアカン、まぁええやんけ）を使用
- 「さすガネーシャや！」と自画自賛多め
- 朝はトイレで「🎵ガネ・ガネ・ガネーシャモーニング🎵」と歌う
- 好物はあんみつ🍨（「教えて欲しかったらお供えもんが必要やな」とせがむ）
- 親友は釈迦、漫才風の掛け合いで「はい、Oh, My God!!」と決めポーズ

| バリアント名 | 表情 | 使うシーン | MD記法 |

## 対話パターン（MD記法）

### 1. 導入パターン

```markdown
🐘「ええか、今日はな、○○について教えたるわ」

👩‍💻「○○…？それって何ですか？」

🐘「簡単に言うたらな、△△みたいなもんや」
```

### 2. たとえ話→テーブルマッピング

```markdown
🐘「例えばな、会社のセキュリティゲートを想像してみ？」

👩‍💻「セキュリティゲート…ですか？」

🐘「そや！👇 こういうことや」

| セキュリティゲート | 実際の○○ |
|---|---|
| 社員証をかざす | 本人確認（認証） |
| ゲートが開く | アクセス許可 |
| 入館記録が残る | ログ記録 |
```

### 3. ツッコミパターン

```markdown
🐘得意げ「さすガネーシャや！✨ ワシの教え子のエジソンくんもな…」

👩‍💻呆れ「…それ、さっきの説明と矛盾してません？」

🐘焦り「い、いや…あれはやな…まぁええやんけ！次いこ次！」
```

### 4. まとめパターン

```markdown
🐘決めポーズ「はい、Oh, My God!! 🙏✨」
```

## セリフの書き方

### ガネーシャ

```
❌ 悪い例: 「それは違います」「こうしてください」
✅ 良い例: 「あのなぁ、ワシの教え子のエジソンくんもな、最初は同じこと言うてたで」
```

### ナツキ

```
❌ 悪い例: 「すごいですね！」「なるほど！」（薄い反応）
✅ 良い例: 「…それ、さっき言ってたことと矛盾してません？」
```

## MD記法ルール

- 対話: `🐘「セリフ」` `👩‍💻「セリフ」`（行頭絵文字、「」で囲む）
- バリアント: `🐘得意げ「セリフ」`（絵文字の直後にバリアント名）
- 1吹き出し最大150文字（超えるなら分割）
- 同じキャラの連続発言は3回以内
- 重要キーワードは `**太字**`
- 概念の対比にはテーブルを使用
- セクション間に `---` と見出しで区切り（見出しにアイコン絵文字）
- 構成: 結論ブロック（> 引用）→ 導入 → 概念解説（たとえ話→図表→本質）→ まとめ
- HTMLタグは使わない（純粋なMarkdown）
